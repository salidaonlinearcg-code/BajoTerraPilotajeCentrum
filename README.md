# BajoTerra Pilotaje Centrum

Este directorio contiene la vista web estática del panel de seguimiento y control de pilotaje.

## Publicación web

Para visualizarlo desde la web, sube esta carpeta completa a GitHub y activa GitHub Pages desde la rama principal.

Archivos importantes:
- index.html: página principal
- logo bajoterra.svg: imagen del logotipo
- .nojekyll: evita procesamiento de Jekyll en GitHub Pages
